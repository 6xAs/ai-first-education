# AI-First Education

Proposta pública de inovação pedagógica para os cursos de TI, com horizonte 2030–2031. AI-First · Human-Centered · Value-Driven.

> O mercado não remunera o esforço de escrever código. Remunera a capacidade de resolver problemas e gerar valor.

## Rodar

Node 22.12+; npm install; npm run dev. Para produção: npm run build; npm run preview.

React, TypeScript, Vite, Motion, Tailwind CSS e Lucide React. Onze capítulos, modo keynote, modo explorar, simulação de agentes e avaliação por evidências. O conteúdo aprovado foi preservado como HTML estático de contingência; as cenas utilizam apenas HTML autoral fixo e as simulações principais têm estado React. Versão offline: public/keynote-offline.html.

## Limites

Sem backend, APIs de IA, autenticação, banco, polling ou telemetria própria. As simulações são conceituais e a rubrica e o piloto não foram validados cientificamente. O horizonte 2031 não é uma previsão garantida. Manter fundamentos técnicos e avaliações individuais sem IA.

## Publicação

Importe este repositório no Vercel (preset Vite, comando npm run build, saída dist). Sem variáveis de ambiente. Não ativar serviços pagos ou funções sem aprovação. Nenhuma licença de reutilização foi atribuída: publicar o código não equivale a licenciar direitos autorais.
