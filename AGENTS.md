# Contratos do projeto

- Preservar a frase central e os princípios AI-First, Human-Centered, Value-Driven. Não confundir AI-First com AI-Only.
- Conteúdo conciso, português brasileiro, design vibrante, mobile-first, interações acessíveis e movimento reduzido.
- Produção exclusivamente estática; proibir polling, APIs reais, cron, funções serverless, analytics próprios e novos serviços pagos sem aprovação explícita.
- Simulações locais com exemplos fictícios identificados; dados externos devem indicar fontes e não transformar hipótese em evidência.
- Validação antes de publicação: npm run build, navegação teclado/toque, todos os 11 capítulos, modo keynote/explorar, simulação iniciar/pausar/reiniciar, rubrica 0–100, fallback sem JS e mobile Safari. Não realizar testes de carga em produção.
- Checkpoints CP-01 narrativa; CP-02 UI e experiência; CP-03 testes e acessibilidade; CP-04 deploy e homologação.
