# Movimento e acessibilidade

Motion para transições de cena, feedback de botões, entrada da simulação e placar. CSS para a identidade visual e órbitas. Respeitar prefers-reduced-motion. Evitar animações de layout caras, vídeos automáticos e animações sem propósito. Simulação usa um único timeout cancelável, apenas quando ativa. Navegação por teclado e toque; tela cheia opcional, conforme suporte. HTML inicial legível sem JS. Sem requisições de rede para simulações.
